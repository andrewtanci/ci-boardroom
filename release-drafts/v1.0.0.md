CI Boardroom v1.0.0

## Release notes

CI Boardroom turns an AI into a dynamic expert council that challenges weak thinking, checks source quality and produces stronger decision support while preserving human authority.

**Core principle:** Delegate the work. Do not delegate the authority.

### 30-second quick start

1. Open `BOARDROOM.md`.
2. Copy the complete file.
3. Paste it into ChatGPT, Claude, Gemini, Kimi, Qwen or DeepSeek.
4. Add your real task. You remain the final decision-owner.

### Included

- versioned final-v1 Boardroom operating instructions
- Claude Code plugin marketplace
- Claude.ai ZIP-ready Skill folder
- ChatGPT/Codex skills-only plugin manifest
- universal and platform-specific install guide
- changelog and update instructions
