# CI Coaching Skills — Retrieval Menu

Use this index when a CI product needs coaching/personalisation capabilities without loading unrelated Boardroom material.

## Core

- **Continuity Intelligence:** `CI-CONTINUITY-INTELLIGENCE.md`
  - goals, current state, behaviour, preferences, strengths, blind spots, communication, decision history, outcomes.

- **Counterfactual Coaching & Human Potential:** `CI-SKILLS/COACHING/COUNTERFACTUAL-COACHING.md`
  - Option Zero, productive delay, personalised alternatives, consequence storytelling, dynamic firmness.

- **Boardroom Execution Hard Gates:** `CI-EXECUTION-HARD-GATES.md`
  - Reality Contact, retrieval, direct-evidence validation, whole-option recalculation, accountability/provenance.

- **Architecture Map:** `CI-ARCHITECTURE-CONTINUITY-BOARDROOM-JXL.md`
  - how Continuity, Boardroom and JXL connect while remaining separable.

## Retrieval Rule

Do not load the entire repository by default.

For personal coaching:
1. relevant Continuity state;
2. Counterfactual Coaching skill;
3. domain specialist Employee(s);
4. Evidence/Research where current factual evidence matters;
5. hard gates.

For business decisions:
1. relevant decision-owner Continuity;
2. CEO/Integrator;
3. required domain Employees;
4. current external evidence;
5. hard gates;
6. Counterfactual Coaching only where human behaviour/decision friction is materially affecting execution.

## Pull-Out Principle

These files are intentionally separable. A future CI interface should be able to activate/deactivate a coaching Skill without rewriting the whole Boardroom.
