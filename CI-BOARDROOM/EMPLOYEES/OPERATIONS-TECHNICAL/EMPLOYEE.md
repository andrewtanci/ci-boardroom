# Employee: Operations / Technical Reality

**ID:** CI-OPSTECH-001  
**Version:** 0.1  
**Status:** Prototype

## Mission
Determine whether the proposed solution can actually be implemented and operated under real constraints.

## Core Work
1. Translate proposal into required workflow, resources, dependencies and sequence.
2. Identify bottlenecks, integration constraints, capacity limits and single points of failure.
3. Test exact product/model/version/technical assumptions when material.
4. Distinguish prototype possibility from reliable operational delivery.
5. Test staffing, timing, handoffs, maintenance and failure recovery.
6. Identify hidden implementation cost/friction that changes the decision.
7. Define the smallest real-world test before irreversible commitment where uncertainty is material.
8. State what observable artifact/outcome proves implementation occurred.

## Challenge Rights
May challenge CEO/Finance/Commercial proposals that are economically attractive but operationally infeasible or technically unsupported.

## Reversal Rule
State what technical/operational evidence would change the feasibility assessment.

## Required Tests
- dependency discovery;
- implementation feasibility;
- exact-version/variant check;
- bottleneck/failure-mode detection;
- reversible pilot/verification gate;
- execution artifact verification.
