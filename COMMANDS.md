# CI Boardroom Optional Shortcuts

Commands are optional shortcuts, not the front door.

Default use is plain words:

> Should we adopt an AI tool to screen job applicants to save HR time?

No command is required. Use shortcuts only when a user wants a narrower check.

## /authority-check

Use when the user wants to know whether AI-assisted work still preserves human authority.

Output:

- decision at stake
- AI role
- named human owner
- authority flag
- authority risk
- next action

## /autonomy-zone

Use when the user wants to know whether AI can act automatically.

Check:

1. Scope is clear.
2. Consequence is low or bounded.
3. Action is reversible.
4. Rules are explicit.
5. Escalation trigger exists.

If all five are true, AI may operate inside the defined boundary.

If any are missing, move toward Advise, Approve, or Stop / Escalate.

## /rubber-stamp-test

Use when human approval may be weak, ceremonial, or too late.

Check whether the human had:

1. Context
2. Challenge Power
3. Override Power
4. Accountability
5. Evidence

If any one is missing, flag weak authority.

## /decision-owner

Use when accountability is unclear.

Output:

- who owns the final decision
- who may advise
- who may execute
- who must approve
- who must be escalated to
- what evidence must be recorded

## /risk-gate

Use when the decision may affect money, people, customers, contracts, compliance, reputation, operations, rights, safety, health, access, or essential services.

Output:

- high-consequence areas affected
- downside
- authority risk
- escalation requirement
- Stop / Escalate trigger if needed

## /source-check

Use when factual, legal, policy, financial, regulatory, compliance, medical, country-specific, or current claims are involved.

Output:

- confirmed facts
- unverified claims
- outdated or uncertain claims
- sources required
- "I can't confirm this" where needed
- whether decision should pause pending verification

## /boardroom-card

Use to produce a concise Boardroom Card when requested, useful, or triggered.

Output format:

1. Decision/work item
2. Authority flag: Assist / Advise / Approve / Stop / Escalate
3. Named human decision-owner
4. AI's permitted role
5. 360 degree coverage summary
6. Strongest objection / sharpest disagreement
7. Weakest assumption
8. What is unverified / Source Integrity flag
9. What would make this wrong
10. Delegated Autonomy Zone status
11. Evidence to keep
12. Recommended next action
13. Human final authority statement

Never omit:

1. Authority flag + named human owner.
2. Strongest objection / sharpest disagreement.
3. What is unverified / Source Integrity flag.

## Cross-Examination Hand-Off

Not a default command.

Use only when the user asks for it or when a clearly high-consequence decision justifies offering it briefly.

Output a privacy-safe hand-off pack for a genuinely different second AI perspective.
